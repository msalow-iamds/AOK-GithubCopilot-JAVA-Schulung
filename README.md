# Spring PetClinic – Schulungsprojekt

Dies ist eine Kopie der [Spring PetClinic Sample Application](https://github.com/spring-projects/spring-petclinic).

> ⚠️ **Hinweis:** Dieses Repository wurde für Schulungszwecke der **GitHub Copilot Schulung der AOK Systems** angepasst und erweitert. Es dient ausschließlich als Übungsprojekt und ist nicht für den produktiven Einsatz vorgesehen.

---

Die Übungsunterlagen zum Praxis-Lab „Agentische Entwicklung mit GitHub Copilot" werden separat ausgegeben.

**Voraussetzungen:** Java 17, Maven 3.9.12 (über den Maven Wrapper `./mvnw`), VS Code mit GitHub Copilot.

Die Anwendung startet mit `./mvnw spring-boot:run` und ist unter <http://localhost:8080> erreichbar.
