# PET-142 – Ungültige Besuchstermine verhindern

| Feld | Wert |
| --- | --- |
| Typ | Story |
| Komponente | Besuche (Visits) |
| Priorität | Mittel |
| Reporter | Fachbereich Praxisorganisation |

## Beschreibung

Als Praxismitarbeiter:in möchte ich, dass beim Anlegen eines Besuchs ungültige Termine abgelehnt werden, damit es keine Fehleingaben und Doppelbuchungen gibt.

Besuche in der Vergangenheit sollen nicht möglich sein, sonntags ist die Praxis geschlossen und pro Tag gibt es nur begrenzt Termine.

## Wo finde ich das in der Anwendung?

**Find Owners** → Besitzer:in suchen → Detailseite → beim Tier auf **„Besuch hinzufügen"** klicken.
